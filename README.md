# HOI-paku

Hearts of Iron IV × 将軍カードゲーム — 改良版 (fork of [iekei/iekei1](https://github.com/iekei/iekei1))

ベースは友人作のHoI4風ブラウザ国家戦略ゲーム。本レポは改善版を公開する。

## 元版からの改善点 (2026-10-08)

- **国家方針アイコン**: Paradox Wiki FilePath API 経由で公式アイコン全1348方針に表示 (旧: テキストのみ)
- **アセット強化**: スタート画面ヒーロー画像 / 方針ツリー背景テクスチャを追加
- **オートセーブ**: 30ゲーム内日ごと + ページを閉じる時に自動保存 (専用スロット)
- **ショートカット**: 1〜5キーで速度切替、Spaceで一時停止/再開
- **タブタイトルにゲーム内日付表示**
- **タブ非表示時に自動一時停止** (マルチプレイ時は無効)
- **高速速度時の描画間引き** でパフォーマンス改善
- **Tailwind CDN削除** (未使用・約300KBのロード短縮)
